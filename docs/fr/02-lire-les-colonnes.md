# Lire les colonnes

px designe le prix et sz la taille exprimee dans la devise de base.
ntl represente le notionnel calcule comme px multiplie par sz.
crossed indique si l ordre a retire de la liquidite au lieu de rester passif.
ntl_pos represente une position exprimee en valeur notionnelle.
Ces abreviations doivent etre normalisees avant jointure avec des donnees d API recentes.
Les types, unites et signes doivent etre verifies colonne par colonne avant toute agregation.
Une valeur vide ne doit jamais etre remplacee silencieusement par zero.
