# Limites et verification

Ce depot ne constitue ni un flux temps reel ni un historique exhaustif garanti du protocole.
Il contient quatre commits et peu de metadonnees sur la methode d extraction initiale.
Les analyses doivent donc distinguer faits presents dans les CSV et hypotheses ajoutees ensuite.
Le seuil market maker doit etre conserve comme parametre visible, jamais comme verite universelle.
Ce parcours repose uniquement sur le README et les schemas observes des trois fichiers CSV.
Aucune installation, compilation, requete API ou execution nouvelle n a ete effectuee.
Aucun resultat financier ou statistique n est revendique comme recalcule ici.
Pour verifier, inspecter les CSV bruts et confronter les periodes aux sources officielles Hyperliquid.
