# Biais de classification

Le seuil de 100 millions USD sur trente jours est une heuristique, pas une identite onchain.
Une adresse changeant de volume peut etre classee differemment selon la fenetre d observation.
Les operations internes, sous-comptes ou regroupements d adresses peuvent brouiller l attribution.
Le filtre non_mm ne signifie donc ni retail pur ni absence totale de tenue de marche.
Les liquidations decrivent les evenements enregistres, pas necessairement leur causalite economique.
Toute visualisation doit afficher periode, seuil, source et date d extraction.
Les conclusions doivent rester robustes a un changement raisonnable du seuil de classification.
